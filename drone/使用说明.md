# ROTOR / 05 · 无人机结构实验室

主文件：`无人机结构实验室.html`。这是自包含网页，Three.js、材质纹理、字体和模型生成代码均在文件中，不需要联网。使用 Chrome / Edge 即可直接打开。

## 插入已有网站

将 HTML 上传到你的网站，复制下面的代码。网页内右上角「嵌入」按钮也可生成代码。

```html
<iframe
  src="./无人机结构实验室.html?embed=1"
  title="无人机结构实验室 · 可交互精细模型"
  style="width:100%;height:760px;border:0;border-radius:16px"
  allow="fullscreen"
  loading="lazy"
></iframe>
```

建议宽度 390 px 以上、高度 640 px 以上；窄屏隐藏侧栏说明并将部件列表改为横向导航。`无人机嵌入示例.html` 是可直接打开的父页面示例。

## 操作

- 左键拖动 / 单指拖动：旋转；滚轮 / 双指：缩放；右键：平移。
- 左侧部件列表或点击模型：切换部件特写。
- 「分层拆解」滑块：机架、主板、电调、电机钟罩、螺旋桨和电池按层分离。
- 「内部剖视」：整机移除顶板、电池和螺旋桨；电机模式抬起钟罩，观察铜线圈与磁钢。
- 「单独查看」：隔离所选子系统。
- 「电机转速」：四电机对转，最高读数 18000 rpm；实际画面采用慢放以看清桨叶。
- 「自动导览」：32 秒结构导览；任意模型操作接管。静置 25 秒后自动导览；系统减少动态效果时不自动启动。
- `R` 重置；`E` 开合拆解。右上角可全屏。

## 链接参数

| 参数 | 效果 |
| --- | --- |
| `?embed=1` | 嵌入模式 |
| `?part=motor` | 直接展示电机内部 |
| `?part=fc` | 直接展示飞控 |
| `?autotour=1` | 打开即自动导览 |
| `?parentOrigin=https%3A%2F%2Fexample.com` | 限定父页面控制消息的来源 |

参数可用 `&` 组合。部件 ID：`overview`、`frame`、`motor`、`fc`、`esc`、`wires`、`prop`、`battery`、`camera`。

## 父页面控制

```js
const frame = document.querySelector('iframe');
frame.contentWindow.postMessage(
  { type: 'rotor05', action: 'part', value: 'fc' },
  location.origin
);
```

动作支持 `part`、`reset`、`explode`（0–1）、`throttle`（0–1）、`view`（`three` / `top` / `front` / `side`）。跨域时使用模型所在网站的 origin。只接受父窗口发来的受限消息，不执行文本脚本。

## 模型内容

- 226 mm 轴距的开放式五寸四旋翼，建模单位 mm；GLB 导出后单位为 m。
- 四套 2207 外转子电机，每台 12 个铜线绕组、14 块磁钢、空心钟罩、通风顶盖、轴承和 M5 桨轴。
- 12 片实体桨叶：闭合翼型放样，沿半径变化的弦长、扭转角与后掠；相邻桨反向。
- 上下碳纤维板、独立机臂、真实通孔、立柱、螺钉、软脚和线夹。
- 飞控：主控芯片、引脚、惯性传感器、存储芯片、电阻电容、镀金焊盘、微过孔、USB-C 和 JST 插座。
- 四合一电调：四组三相功率级、24 颗 MOSFET、驱动芯片、焊点、低 ESR 电容。
- 十二根电机相线、八芯飞控排线、XT60 插头、粗硅胶电源线、镜头与接收机线束。
- 六层 LiPo 电芯、热缩包装、双固定束带、前置镜头和后置接收机天线。

这是用于展示结构与工作关系的工程可视化模型。飞控参考 F405 类商品板布局，走线为视觉示意；不是可制造 CAD、可生产 PCB 或飞行性能求解器。

## 源码与构建

`drone/model.js` 几何、装配、材质；`stage.js` 灯光、相机；`console.js` 页面；`data.js` 说明与导览；`main.js` 交互、嵌入接口与 GLB 导出；`style.css` 响应式布局。

本机重建：`node drone/build.mjs`。浏览器检查：`node drone/verify.mjs`。构建使用 teardown 技能中已有的本地依赖。

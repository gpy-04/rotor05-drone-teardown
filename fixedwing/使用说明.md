# 固定翼无人机结构实验室

写实双尾撑、后置推进固定翼无人机，主体和全部零件均不含商标、品牌丝印或品牌涂装。主网页为自包含 HTML，约 882 KB，无需网络、后端或 CDN。

## 打开

用开启硬件加速的 Chrome 或 Edge 打开根目录的 `固定翼无人机结构实验室.html`。`固定翼无人机嵌入示例.html` 展示 iframe 与外部按钮控制。GLB 模型单位为米，可导入支持 glTF 的三维软件。

## 操作

- 鼠标拖动旋转、滚轮缩放、右键平移；触屏可以拖动和双指缩放。
- 左侧九个入口切换整机、机身、主翼、尾翼、动力、电子设备、电池、光学载荷和起落架。
- 「内部剖视」隐藏上半蒙皮，电机视图分离钟罩和桨毂。「单独查看」切换子系统隔离。
- 「分层拆解」连续展开装配，电机转速滑块对应 0–8,200 rpm。桨叶运动使用视觉慢放。
- 「舵面控制」操作副翼、升降舵、方向舵和襟翼。副翼、升降舵及其舵机连杆由同一状态驱动。
- 「自动导览」提供 40 秒、7 个章节的循环导览；任何交互接管控制。静置 45 秒后恢复导览。系统要求减少动态效果时不自动恢复。
- 双击或按 R 回到整机，E 展开或收拢装配。

## 参数与结构

翼展 2.4 m，全长 2.13 m；根部弦长 0.44 m、翼尖弦长 0.27 m。主翼采用 NACA 2412 解析截面，3° 上反角，翼尖 −2° 几何扭转。参考面积按梯形平面并包含机身中心投影计算：`2.4 × (0.44 + 0.27) / 2 = 0.852 m²`。

机身蒙皮有 2.4 mm 厚度；内部隔框、设备托盘、翼肋、主后翼梁、铰链、舵机、连杆、软包电芯、插头、三相线路和镜头均有独立几何。电机包含 12 槽定子、14 极磁钢、铜线圈和空心钟罩。螺旋桨使用具有弦长变化和扭转的闭合翼型实体。

本模型用于结构展示。外形参考实际双尾撑推进式飞行器，尺寸、设备和 PCB 布局是无品牌教学设计，未进行气动性能认证、制造公差验证或电路设计验证。

## 嵌入和接口

```html
<iframe src="./固定翼无人机结构实验室.html?embed=1"
  title="固定翼无人机结构实验室"
  style="width:100%;height:760px;border:0;border-radius:12px"
  allow="fullscreen" loading="lazy"></iframe>
```

页面参数：`?embed=1` 嵌入模式，`?autotour=1` 开始导览，`?part=wing` 或 `?part=motor` 直达子系统，`?quality=low` 降低像素比及阴影分辨率。`?parentOrigin=https://example.com` 限定允许控制的父页面来源。

父页面可发送：

```js
iframe.contentWindow.postMessage({type:'fixedwing',action:'part',value:'wing'}, '*');
iframe.contentWindow.postMessage({type:'fixedwing',action:'explode',value:1}, '*');
iframe.contentWindow.postMessage({type:'fixedwing',action:'throttle',value:.35}, '*');
iframe.contentWindow.postMessage({type:'fixedwing',action:'controls',value:{roll:.5,pitch:.3,yaw:0,flap:.2}}, '*');
iframe.contentWindow.postMessage({type:'fixedwing',action:'reset'}, '*');
```

只接受父窗口发送的消息，所有数值经过范围限制。正式部署建议将 `'*'` 换成已知目标来源。

开发检查接口：`window.fixedwing.getState()`、`setState()`、`audit()`、`view()`、`seek(t)`、`diagnostic('normals'|'wireframe'|'final')`。重建使用 `node fixedwing/build.mjs`，验证使用 `node fixedwing/verify.mjs`。本机重建依赖 teardown 技能的 Node.js 工具链，已构建网页无需安装。
